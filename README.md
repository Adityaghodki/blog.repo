📝 Blogging Platform (Frontend)

A collaborative React-based blogging platform that enables users to read, create, search, comment on, and share blog posts, with admin controls and modern UI components.
Built as a team project with continuous improvements, UI refinements, and feature expansion.

🚀 Features
📰 Blog Management

Create and publish blog posts

View detailed blog content

Blog cards for structured previews

Blog information pages with metadata

🔍 Search & Discovery

Search dialog for finding blogs

Improved search experience through UI updates

💬 Interaction

Comment system for blog posts

Share dialog for sharing blog content

Interactive blog cards and dialogs

🧑‍💼 Admin Panel

Admin login functionality

Admin dashboard for management

Admin panel bug fixes and UI improvements

🧭 Navigation & UI

Responsive navigation bar

Dashboard page for users/admins

UI updates across navbar, blog pages, and dialogs

Cleaned and optimized components

🧱 Tech Stack

Frontend: React.js

State Management: Context API (myState.jsx)

Styling: CSS / Component-based styling

Authentication: Firebase

Editor & Media: Tiny Cloud API

Hosting: GitHub Pages (CNAME configured)
